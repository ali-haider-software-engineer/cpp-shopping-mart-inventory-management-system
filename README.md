# Console-Based Shopping Mart Inventory Management System (C++)

This project is a console-based Shopping Mart Inventory Management System
developed using C++ during my first semester as a Software Engineering student.

## Features
- Add new products with unique ID
- Display all products in a formatted table
- Search products by ID
- Update product price and quantity
- Delete products from inventory
- Menu-driven console interface

## Programming Concepts Used
- Arrays
- Functions
- Conditional statements (if-else, switch)
- Loops
- Input/output formatting (iomanip)
- Modular programming

## How to Run
1. Open the project in any C++ compiler (Visual Studio)
2. Compile and run `main.cpp`
3. Use the menu options
